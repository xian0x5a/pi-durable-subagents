# Prepare reused Agents with an optional working zone

A delegating Agent may assign a Continuation Delegation to an existing Agent through an ordinary Agent Request when that Agent's acquired context materially reduces rediscovery. The Request may carry non-model-visible `contextPreparation` intent with required `workScale` (`small`, `medium`, or `large`) and `contextDependence` (`low`, `medium`, or `high`). Omission preserves Pi's native compaction behavior. Reuse remains trust-based ordinary delegation with no new eligibility, routing, authority, or lifecycle state.

Working-Zone Preparation compares the recipient's current context `C` against an absolute dependence cost threshold: 95,000 tokens for Low, 127,000 for Medium, and 159,000 for High. Desired runway starts at 16,000, 32,000, or 64,000 tokens for Small, Medium, or Large work and is multiplied by the recipient's actual thinking level: 1.0 for Off through Low, 1.5 for Medium, 2.0 for High, 2.5 for XHigh, and 3.0 for Max. With context window `W` and model-visible incoming Request estimate `Q`, the recipient computes `Trunway = max(0, W - Q - desired runway)`. When `Trunway < Tcost`, `Teffective = 0.7 × Tcost + 0.3 × Trunway`; otherwise, `Teffective = 0.85 × Tcost + 0.15 × Trunway`. The stronger shrinkage weight responds to insufficient runway, while the smaller expansion weight lets larger context windows delay compaction without letting runway dominate the dependence cost. It prepares only when automatic compaction is enabled, the recipient is idle, current usage is known, and `C > Teffective`. Unknown or unavailable runway inputs use `Tcost` alone; unavailable current usage skips preparation.

The child Turn Compaction Gateway invokes the recipient's public Active Compaction Strategy at most once before exact Request Delivery commitment and releases admission before the model cycle. Pi or an extension owns the target, retained context, persistence, diagnostics, and fallback behavior. The prospective Request may guide which existing context Pi summarization preserves but must not appear in or be asserted by the summary; strategies that ignore custom guidance remain valid. Active Steer Delivery preserves its mode and skips proactive preparation. Preparation failure warns in the child and continues Delivery, leaving Pi's own start check to apply its native threshold, while cancellation and Runtime-generation fencing keep their existing behavior. Later prepared Requests recompute without cooldown state, and transcript evidence remains the sole Delivery authority.
